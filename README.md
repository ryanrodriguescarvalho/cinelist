# CineList — Catálogo de Filmes e Séries

Projeto React + Vite para atividade prática.

## Executar
1. Instale o Node.js.
2. Abra esta pasta no VS Code.
3. Abra o terminal e execute `npm install`.
4. Execute `npm run dev`.
5. Abra a URL exibida no terminal (geralmente http://localhost:5173).

## Conceitos utilizados
- **Componentização:** `Header`, `AddForm` e `ItemList`.
- **useState:** controla formulário, catálogo e filtro.
- **Formulário controlado:** `value` + `onChange`.
- **.map() e key:** exibem os cards dinamicamente.
- **.filter():** exclui itens sem alterar o array original e filtra a visualização.
- **useEffect e localStorage:** salvam os itens no navegador.
- **CSS:** visual responsivo, cards e tema escuro.
